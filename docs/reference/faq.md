# FAQ

Short answers for the visual check.

## Where did the right-hand list go?

Into the left navigation, under the page you have open. That is `toc.integrate`.

## Why is the article still narrow?

The IDP reader reserves width for two sidebars. Hiding the list does not yet give that width back.

## Does this apply to every docs site?

No. Only sites whose `mkdocs.yml` includes the feature. This repository is one site.

## Which page should I open first?

Platform, then Architecture. It has the longest heading tree.
